This add-on is a fixed version for Anki26+ of the addon <a href="https://ankiweb.net/shared/info/1102281552" target="_blank">"Special Fields"</a>, originally created by <a href="https://github.com/johnpincock/SpecialFields" target="_blank">John Pincock</a> and credit goes to them. (contributors: AnKingMed, Arthur-Milchior, hgiesel, abdnh, RisingOrange, BlueGreenMagick) The original add-on is no longer maintained and is broken in the latest version of Anki, instead you can use this my fixed version. (Fork, AGPL)

## How to use

Please read the description and watch the tutorial video for the [original add-on page.](https://ankiweb.net/shared/info/1102281552)

## Note

Since this add-on is new, there may be a risk of unexpected issues. If you're concerned please back up your decks before using the add-on and check to see if it works properly, if you encounter any issues please contact me.

## 📥 How do I install this add-on?

1. This add-on works with Anki for desktop (it does not work on mobile). Download Anki from the [official website](https://apps.ankiweb.net/) if you haven't already.
2. Copy and paste the add-on code ( `92238674` )  into Anki and you can install it. ( *Menu -> Tools -> Add-ons -> Get Add-ons -> Code \[ add-on code ]* )
3. When I develop bug fixes, create new features, or compatibility for New Anki, I will notify you and you can install it.
4. Add-ons will be broken when the official Anki gets a major update, so if you like this add-on please support my volunteer development by rating, sharing, and donating. Thank you!
